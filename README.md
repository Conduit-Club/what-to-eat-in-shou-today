# what-to-eat-in-shou-today
今日海大吃什么项目。理论上是水专手册的子项目，用于收集同学对于海大以内以及周围餐厅、餐馆的观点。

## 本地预览

使用 Pixi 安装依赖并启动本地开发服务器：

```bash
pixi install
pixi run dev
```

然后访问 <http://127.0.0.1:8000/>。

构建静态网站：

```bash
pixi run build
```
