# 一食堂

## 位置

本科生宿舍区附近的第一食堂，窗口分布在一楼和二楼。一餐一楼指第一食堂一楼，本页沿用同学的简称。

## 消费范围

- 一楼铁板饭、铁板鸡排：同学分享约 8 元/份。
- 一楼锅贴：同学回忆约 1 元至 1.5 元/个，更早为一元。
- 二楼酸菜鱼：同学分享约 19 元/份。
- 其余窗口和现价待补充。

以上金额来自同学分享和回忆，没有对照现场价目表，也没有记录具体用餐日期。

## 注意事项

- 一楼有早餐、大伙打菜的整排窗口，以及面食、馄饨、酱香饼、铁板等窗口；二楼有现煮酸菜鱼和滑蛋饭等。
- 同学还提到一餐炸物窗口的鸡排、鸡腿，但没有说清在一楼还是二楼。
- 新上的生滚粥目前还没有同学评价。
- 档口和价格会随学期调整，以现场窗口和价目表为准。

>
> —— A

> —— C

> 一餐二楼的酸菜鱼是现煮的，油一泼上去特别香，就是有花椒会有点呛，略微小贵，19 块，但是肯定是值得的。
>

> 我将永远追随一餐一楼的铁板鸡排。
>

>

这条评价没有说明铁板烧属于哪个食堂或窗口，暂不据此断定在一食堂。
