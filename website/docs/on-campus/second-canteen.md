# 二食堂

## 位置

本科生宿舍区附近的第二食堂，一楼和二楼都有窗口。二楼靠外侧的窗口是[风味餐厅](flavor-restaurant.md)。二餐一、二餐二分别指第二食堂一楼和二楼。

## 消费范围

- 二楼风味餐厅牛肉面：同学分享约 8 元/碗。
- 其余窗口和现价待补充。

价格来自同学分享，没有对照现场价目表，也没有记录具体用餐日期。

## 注意事项

- 一楼有打菜窗口、砂锅窗口，以及蜜雪冰城；二楼有炸鸡、酸辣粉、凉皮、葱油拌面，以及烧腊、河南烩面（含炒刀削之类的炒面）等窗口。
- 砂锅以前配小青菜，后来换成大白菜。
- 档口和价格会随学期调整，以现场窗口和价目表为准。
