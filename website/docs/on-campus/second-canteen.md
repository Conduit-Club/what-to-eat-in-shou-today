# 二食堂

## 位置

本科生宿舍区附近的第二食堂，一楼和二楼都有窗口。二楼靠外侧的窗口是[风味餐厅](flavor-restaurant.md)。同学说的“二餐一”“二餐二”，分别指这里的一楼和二楼。

## 消费范围

- 二楼风味餐厅牛肉面：约 8 元/碗。
- 其余窗口和现价待补充。

价格是同学说的，没对过现场价目表，也没记下具体是哪天吃的。

## 注意事项

- 一楼有打菜和砂锅窗口，还有蜜雪冰城；二楼有炸鸡、酸辣粉、凉皮、葱油拌面，也有烧腊和河南烩面的炒刀削一类炒面。
- 砂锅以前配小青菜，后来换成了大白菜。
- 档口和价格每学期都可能变，以现场为准。
