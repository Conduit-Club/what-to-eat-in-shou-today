# 校外吃什么

这里整理学校周边和附近商圈的餐饮选择。建议出发前确认店铺是否营业，以及优惠活动是否仍然有效。

## 店家列表

- [潮汕牛肉粿条](shantou-beef-noodles.md)：学校旁，同学评价不错。
- [比格披萨自助](big-pizza.md)：披萨自助，价格和菜品会变化。
- [必胜客汉堡](pizza-hut-burger.md)：汉堡单品，原价性价比评价较低。
- [泰妈](taima.md)：同学评价较高，位置待补充。
- [今牛](jinniu.md)：同学评价较高，位置待补充。
- [陶瑞酒店一楼餐厅](taorui.md)：位置明确，但尚无实际用餐评价。
- [汉堡王](burger-king.md)：优惠券价格曾经较低，当前价格待确认。
- [甜品铺叉烧饭](dessert-bbq-pork-rice.md)：店名和位置待确认。
- [南昌特色瓦罐汤](nanchang-pot-soup.md)：瓦罐汤评价尚可，其他菜品评价一般。
- [江西小炒](jiangxi-stir-fry.md)：六院对面有一家同学评价不错。
- [久锅子潮汕牛肉火锅](jiuguozi.md)：新天地附近，潮汕牛肉火锅评价很高。
