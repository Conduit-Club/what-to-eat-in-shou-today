# 今日海大吃什么

## 项目简介

这是一个面向海大学生的餐饮信息收集项目，记录海大校内及周边餐厅、餐馆的就餐体验与同学评价，帮助大家更轻松地决定：

> 今天吃什么？

## 内容规划

后续将逐步整理以下信息：

- 餐厅位置与营业时间
- 人均消费与推荐菜品
- 口味、分量和性价比评价
- 适合堂食、外带或聚餐的场景
