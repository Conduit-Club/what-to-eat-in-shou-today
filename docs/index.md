# 今日海大吃什么

这是一个面向海大学生的餐饮信息手册，收集校内外餐厅、餐馆和小吃店的同学体验，帮助你快速决定今天吃什么。

## 使用指南

按就餐范围浏览：

- [校内吃什么](on-campus/index.md)：适合不想出校、想快速解决一餐时查看。
- [校外吃什么](off-campus/index.md)：整理学校周边及附近商圈的店铺。

每家店的页面会尽量提供：

- **位置**：店铺所在区域或地标
- **消费范围**：目前收集到的人均或套餐价格
- **注意事项**：价格波动、优惠活动、菜品稳定性等
- **同学评价**：保留不同同学的个人体验，不等同于统一结论

## 信息说明

本手册内容来自同学分享，价格、营业状态和菜品可能发生变化。带有“待补充”的内容，欢迎提供更具体的位置、价格、照片或最新体验。

## 参与贡献

欢迎补充你吃过的店铺和真实体验。建议注明店铺、位置、消费金额、用餐时间，并区分个人口味与可以核实的事实。
